# Fritz Portfolio

Open `index.html` in a browser.

## Folder structure
- index.html
- css/style.css
- js/main.js
- assets/images/fritz.png        <- Home photo (replace with transparent PNG cutout)
- assets/images/fritz-about.png  <- About photo (replace with transparent PNG cutout)
- assets/images/works/           <- 9 work images (social-1..3, jersey-1..3, sports-1..3)
- assets/icons/                  <- social icons (placeholder SVGs, swap with real logos)

## Replace the photos
The current fritz.png / fritz-about.png are cropped from your layout (they include the dark background).
Export your photo from Photoshop as a transparent PNG with the same file names for the best result.
Replace the work images with your original full-resolution exports (same file names).
